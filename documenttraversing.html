Course Modules

UI/UX Prototyping

User Interface and User Experience design focuses on creating intuitive digital products. This involves building wireframes, designing interactive prototypes in Figma, and mapping out logical user flows to ensure seamless navigation across web and mobile platforms.

Vector Graphic Design

Graphic design relies heavily on scalable vector artwork for brand identity. Using industry-standard tools like Adobe Illustrator and CorelDRAW, designers craft logos, typography layouts, and complex asset compositions that retain full resolution at any scale.

Front-End Web Development

Front-end development brings digital designs to life using HTML structure and CSS styling. It ensures that custom web layouts are fully responsive across different devices, utilizing flexbox alignment and media queries to adapt to various screen sizes.

Vertical Video Production

Modern commercial campaigns often prioritize 9:16 vertical video formats optimized for social media. This process requires precise frame-by-frame pacing, motion graphics integration, and dynamic text overlays to capture audience attention within seconds.

Cross-Platform Applications

Developing functional applications that work seamlessly across desktop and mobile requires versatile frameworks. This involves configuring code properties, adjusting permissions, and compiling final packages, such as Python-based Android APK builds.
